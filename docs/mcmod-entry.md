## 一句话介绍

一个**不需要额外 EMC 接口方块**的 ProjectE × Refined Storage 联动：把 EMC 商店直接挂到 RS 网络上，存入自动处理、取出真实库存优先，并带**转化桌进度门槛**和**附魔/NBT 保护**。

## 它解决什么问题

传统 ProjectE × RS 联动通常要额外摆一个“EMC 接口方块”，每个网络单独配置，还要手动切换“买/卖”模式。

本模组改为**网络级共享**：

- 不需要新方块，不占用地形；
- 一个 RS 网络对应一个 EMC 主人；
- 终端里直接看到可购买的已学习物品；
- 存入的物品可以自动转化为 EMC；
- 取出时优先消耗网络真实库存，不足再扣 EMC。

## 核心功能

### 1. 网络级 EMC 商店，无额外方块

- 虚拟 EMC 库存直接注入 RS 网络存储缓存。
- 终端里显示主人**已学习**、有 EMC 价值、且不在 `buy` 黑名单中的物品。
- 不需要合成/放置 EMC 接口，也不需要在每个网络重复摆放。

### 2. 存入自动处理，取出自动扣 EMC

- 往 RS 网络插入物品时，先经过自动回收存储。
- 有 EMC 回收价值的普通物品可自动转化为网络主人的 EMC。
- 取出时：**先扣真实 RS 库存，真实库存不足才按 EMC 价值扣主人 EMC**。
- 没有 EMC 价值的物品不会被消耗，会交给普通 RS 存储。

### 3. 转化桌进度门槛（3.3.0 新增）

这是一道**防跳进度**的检测：

- **未获得转化桌或便携转化桌（Transmutation Tablet）时：**
  - RS 终端不显示 EMC 可购买物品；
  - 不能用 EMC 取出任何物品；
  - 默认存入时只**记录知识**并把物品正常存进 RS，**不产生 EMC**；
  - Ctrl 批量回收也会被锁定。
- **获得过以下任意一项后，该玩家永久解锁：**
  - 背包里有转化桌或便携转化桌；
  - 放置过转化桌方块；
  - 已完成 ProjectE 对应进度。
- 解锁按玩家 UUID 记录，之后放置、丢失、换网络都不会重新锁定。

### 4. 附魔 / NBT 保护（3.2.2 起）

- 默认**不会**自动回收带 NBT 的物品：
  - 附魔物品、附魔书
  - 有耐久的工具/武器
  - 药水
  - 自定义名称、自定义 NBT
- 这些物品会正常进入 RS 存储，附魔和 NBT 原样保留。
- 真正没有 EMC 价值的物品也**绝不会被自动消耗**。
- 只有显式设置 `sellNbtItems = true` 才会强制自动回收 NBT 物品（会丢失附魔/耐久，不建议）。

### 5. EMC 余额与数量同步

- RS 终端物品栏上方右侧显示金色 **EMC 余额**。
- 虚拟可购买数量每约 1 秒按实时 EMC **增量同步**。
- 使用 RS 原生物品增量包更新，不重建缓存、不改变条目 UUID；数量准确的同时不会出现“点不出来”。

### 6. buy / sell 黑名单

`config/emc_rs-common.toml` 支持两个黑名单：

- `buy`：不能用 EMC 购买的物品（真实库存仍可取出）。
- `sell`：插入网络时不会被自动转成 EMC，正常存储。
- 支持物品 ID 和 `#tag`，不支持按 NBT 精确匹配。

### 7. EMC 侧边按钮

打开方块 RS 终端后，右侧有 EMC 控制按钮：

| 操作 | 效果 |
| --- | --- |
| 普通点击 | 查看状态；首次点击绑定当前玩家为网络 EMC 主人 |
| Shift + 点击 | 重新绑定 EMC 主人（当前主人或 OP） |
| Ctrl + 点击 | 按终端右侧 4 个过滤槽批量回收网络真实库存（跳过 sell 黑名单） |

## 使用流程（单人）

1. 安装 Forge 1.20.1、ProjectE、Refined Storage，把 `emc_rs-3.3.0.jar` 放入 `mods/`。
2. 正常放置 RS 控制器，接上 RS 终端和**真实存储盘/存储块**。
3. 控制器由你放置时会自动成为网络 EMC 主人；否则打开方块终端点一次 EMC 按钮绑定。
4. **未获得转化桌/便携转化桌时：**
   - 终端不显示 EMC 商品；
   - 往网络放物品只记录知识并正常存储，不产 EMC；
   - 不能用 EMC 取出。
5. 获得转化桌/便携转化桌后，该玩家永久解锁：
   - 终端开始显示 EMC 可购买物品；
   - 取出时真实库存优先，不足扣 EMC；
   - 普通物品存入可自动转 EMC（受 `sell` 黑名单保护）。
6. 批量回收已有库存：把物品放入终端右侧 4 个过滤槽，Ctrl 点击 EMC 按钮。

## 配置

文件：`config/emc_rs-common.toml`（首次启动生成）

```toml
[blacklist]
    buy = []
    sell = []

[automation]
    sellNbtItems = false

[progression]
    requireTransmutationTable = true
    convertWithoutTable = false
```

### 选项说明

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| `blacklist.buy` | 空 | 不能用 EMC 购买 |
| `blacklist.sell` | 空 | 不会被自动转 EMC，正常存储 |
| `automation.sellNbtItems` | false | true 时强制自动回收带 NBT 物品（会丢附魔） |
| `progression.requireTransmutationTable` | true | 未获得转化桌/平板时锁定 EMC 取出 |
| `progression.convertWithoutTable` | false | 未获得桌子时存入只学习+存储，不产 EMC；true 则仍自动转 EMC 但仍不能取出 |

修改后需要重启游戏/服务器。

## 重要限制

- **AI 创作**：本模组代码、设计、文档、封面由 AI 创作/实现。
- **需要真实 RS 存储**：虚拟 EMC 存储只提供“用 EMC 购买”的虚拟条目，不存储真实物品。无 EMC/带 NBT 的物品必须进入真实存储盘/存储块；没有存储或空间不足时会弹回背包。
- **单人使用优化**：一个网络只有一个 EMC 主人（控制器放置者/绑定者），使用该主人的知识/EMC。
- **主人必须在线**：主人离线时终端不显示可购买物品，也不能自动回收。
- **只读取玩家面板上的 EMC**：转化桌输入槽或 Klein Star 内的 EMC 不会被读取。
- **EMC 按钮只加在方块 RS 终端上**；便携/无线终端可以看物品、按 EMC 取出，但没有按钮。
- 只处理物品，不处理流体。
- 仅适用于 1.20.1 + RS 1.12.x + ProjectE 1.0.x。

## 常见问题

### Q：为什么无 EMC 或带 NBT 的物品放不进 RS 网络？

先确认网络里有**真实 RS 存储盘/存储块**并且还有空间。虚拟 EMC 存储不是真实物品存储；没有落点就会退回。

### Q：为什么终端里看不到 EMC 可购买物品？

检查是否已经获得**转化桌或便携转化桌**。3.3.0 默认在获得前锁定 EMC 取出；获得后会自动解锁。

### Q：为什么附魔物品没有自动变成 EMC？

3.2.2 起默认保护所有带 NBT 的物品，避免附魔/耐久丢失。要强制回收需设置 `sellNbtItems = true`，但不建议。

### Q：为什么数量不刷新？

虚拟数量每约 1 秒增量同步。如果界面因其他原因没有变化，重新打开终端会收到完整列表。

### Q：能把 EMC 取出改成获得桌子前也能用吗？

把 `progression.requireTransmutationTable` 改为 `false` 即恢复旧行为。

### Q：获得桌子前想继续自动转 EMC 怎么办？

把 `progression.convertWithoutTable` 改为 `true`：仍会产 EMC，但 EMC 取出仍锁定，直到获得桌子。
